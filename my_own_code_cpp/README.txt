ПРОЕКТ ОБРАБОТКИ ГИТАРНОГО WAV-СИГНАЛА
======================================

СОСТАВ ПРОЕКТА
--------------
main.cpp          Главная программа: загрузка аудио, применение эффектов и сохранение результатов.
wav_reader.h      Объявления структур и функций для чтения и записи WAV.
wav_reader.cpp    Реализация чтения и записи WAV PCM 16 бит.
visualize.py      Воспроизведение WAV-файлов и построение графиков из CSV.
run.bat           Компиляция C++, обработка аудио и запуск Python-скрипта.
requirements.txt  Зависимости Python.
input.wav         Входной файл; его нужно положить в папку проекта.

ПОДДЕРЖИВАЕМЫЙ ФОРМАТ WAV
-------------------------
- Контейнер RIFF/WAVE.
- Несжатый PCM (Audio Format = 1).
- Разрядность 16 бит.
- Один или два канала: моно или стерео.
- Чанк fmt может иметь дополнительные поля после обязательных 16 байтов.
- Между чанками могут находиться дополнительные RIFF-чанки.

Сжатый WAV, PCM 24/32 бит, WAV с плавающей точкой и RF64 не поддерживаются.

ПОДГОТОВКА
----------
1. Установить компилятор g++ (например, MinGW-w64) и добавить его в PATH.
2. Установить Python и добавить его в PATH.
3. Открыть терминал в папке проекта и установить библиотеки:

   python -m pip install -r requirements.txt

4. Положить исходный WAV-файл в папку проекта и назвать его input.wav.

ЗАПУСК
------
Запустить run.bat двойным щелчком мыши.

Также можно передать другие имена входного файла и папки результатов:

   run.bat "моя_запись.wav" "результаты"

РЕЗУЛЬТАТЫ
----------
В папке output будут созданы:
- output_original.wav
- output_tremolo.wav
- output_vibrato.wav
- original_graph.csv
- tremolo_graph.csv
- vibrato_graph.csv

WAV-файлы можно прослушать, а CSV-файлы используются Python для построения графиков.

ПАРАМЕТРЫ ЭФФЕКТОВ
------------------
Параметры задаются в начале функции main() файла main.cpp:

TREMOLO_RATE       Частота модуляции Tremolo в герцах.
TREMOLO_DEPTH      Глубина Tremolo от 0 до 1.
VIBRATO_RATE       Частота модуляции Vibrato в герцах.
VIBRATO_DEPTH_MS   Глубина изменения задержки Vibrato в миллисекундах.
